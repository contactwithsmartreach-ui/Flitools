How it works

Password Studio generates random passwords entirely inside your browser, using the same cryptographically secure random source browsers use for encryption keys. Nothing is ever sent to a server, and nothing generated here is stored.

1

Set the length

Choose anywhere from 4 to 64 characters. Longer passwords are exponentially harder to crack.

2

Pick character sets

Mix in uppercase, lowercase, numbers, and symbols, or exclude visually ambiguous characters for easier reading.

3

Generate

Your browser draws truly random bytes from the Web Crypto API and maps them to your chosen character set — no upload, no waiting on a server.

4

Copy

Copy one password or a whole batch. Nothing generated here is ever transmitted or saved anywhere.
